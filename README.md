# Vibration Control of Mechanical Structures via Inerter Devices

## 📌 Project Overview
Research project focused on controlling mechanical structural vibrations through the integration of an inerter. The study models dynamic behavior under complex excitations and evaluates passive control efficiency.

## 🛠️ Methodology & Tools
- **Mathematical Modeling:** Formulated differential equations governing structural dynamics with non-linear excitations.
- **Numerical Simulation:** Implemented dynamic solvers to evaluate vibration reduction performance.
- **Tools Used:** MATLAB, FORTRAN.

## 🔑 Key Deliverables
- Numerical simulation scripts for structural response.
- Performance evaluation of inerter-based absorbers.
